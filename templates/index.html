🎯 Ranking Kelly — un pick por partido 0

Un solo score 0–10 por partido (Kelly Criterion: probabilidad real + cuota). Sin EV%/probabilidad sueltos — para el detalle completo de cada mercado, esos números siguen en "Todos los Juegos". Los partidos sin score suficiente no aparecen acá: no se marcan EVITAR, simplemente no están. Tickets/Parlays usan este mismo score.

Cómo se calcula
score = clamp( kelly_usado × 200, 0, 10 )
kelly_usado = kelly_completo × 0.25 × confianza_libros
kelly_completo = p − (1−p) / b
b = cuota_decimal − 1 confianza_libros = clamp(casas / 4, 0, 1)
p = probabilidad real sin vig. El ×0.25 es Kelly fraccional (full Kelly es demasiado agresivo). confianza_libros reutiliza el mismo shrink que ya usa el ranking por edge en Eficiencia.

Piso para aparecer: score ≥ 2.0. Tickets/Parlays usan el mismo piso y el mismo score — nunca deberían mostrar un pick que acá no calificaría.
