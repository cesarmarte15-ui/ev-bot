# EV Bot Pro v5 Clean

Tres colores:
- Verde: Seguridad a jugar
- Azul: Partidos probables
- Rojo: Evitar

Cambios:
- Pick 1 por partido: Moneyline.
- Pick 2 por partido: Spread o Total, nunca repite ML.
- Parleys: Seguro, Probable o Agresivo.
- Mercados usados: h2h, spreads, totals.
- Cache para controlar créditos.
